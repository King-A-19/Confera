# Confera — Event Planning Platform

Confera is a full-stack event planning application designed to simplify the process of organising events. Users can create events, select venues, manage catering and equipment, estimate costs, and manage their saved events in one place.

# Features

User Authentication — Register and log in to your account.

Event Planning — Create events with names, dates, attendee counts, and event types.

Venue Selection — Choose a venue and account for venue costs.

Catering Management — Select catering options and calculate costs.

Equipment Management — Add event equipment and include its cost in the budget.

Budget Estimation — Calculate venue, catering, equipment, and total event costs.

My Events — View and manage your saved events.

Edit and Delete Events — Update event details or remove events with a confirmation dialog.

Persistent Storage — Store user accounts and event data in PostgreSQL.

Responsive Navigation — Navigate the application across desktop and mobile screens.
